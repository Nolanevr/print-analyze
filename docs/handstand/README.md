# Handstand Plan

A phone app for the Beginner Calisthenics & Handstand Plan: guided workouts, rest and hold
timers, a 10-minute version for low-energy days, XP, levels, weekly streaks and badges.

It is a single-page web app that installs to the home screen and works offline. Progress is
saved on the phone.

## Hosting (GitHub Pages)

Settings → Pages → Build and deployment → Source: **Deploy from a branch** → pick the branch
that holds this folder and the **/docs** folder → Save. The app is then at
`https://<user>.github.io/<repo>/handstand/`.

## Installing on a phone

- iPhone: open the link in Safari → Share → Add to Home Screen.
- Android: open the link in Chrome → Install app (or ⋮ → Add to Home screen).
